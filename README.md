## Featured work

### Research Team Lead — [AuraBeam](https://github.com/Azios1010/aura_beam)

`04/2026 – 05/2026`

- Led a small research team from system concept to a working adaptive anti-glare headlight prototype
- Developed a perception-to-control pipeline combining vehicle detection, temporal depth estimation, actuation-aware 3D tracking, and LED-grid hardware-in-the-loop evaluation
- Evaluated glare suppression, false darkening, tracking performance, and CPU latency under nighttime conditions
- Authored [Robust Nighttime Vehicle Localization Under Headlight Saturation via Ensemble Detection and Actuation-Aware 3D Tracking](https://azios1010.github.io/portfolio/papers/robust-nighttime-vehicle-localization-aura-beam.pdf), submitted to MVA and currently under review

### Banking Operations RAG System

- Developed a modular backend for a banking-domain retrieval-augmented generation assistant
- Implemented document ingestion, text chunking, embedding generation, vector indexing, semantic retrieval, and context-grounded response generation
- Added persistent vector-store loading to reduce repeated processing and improve maintainability
- Currently exploring how retrieval pipelines can be extended with tool use and multi-step orchestration

### Media Crisis Sentiment Analysis

- Built a Vietnamese sentiment-analysis pipeline for tracking public responses during media crises
- Evaluated PhoBERT- and SVM-based classifiers, achieving an F1 score of **0.83** on the project dataset
- Performed data preprocessing, model training, hyperparameter tuning, and experimental evaluation
- Contributed experimental findings to a research manuscript
